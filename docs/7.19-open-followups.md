## 1. [MUST BEFORE PROD] `clause_redlines` junction race — accept path

The accept path needs a `SELECT … FOR UPDATE` (or a unique partial index) to
close the same-clause race. Filed earlier as the concurrency follow-up.

- The in-txn conditional flip (`WHERE status = 'PROPOSED'`) already makes two
  accepts of the **same redline** correct. What is open is two **different**
  PROPOSED redlines on the **same clause** accepted concurrently — each flips its
  own row, so both conditionals succeed.
- Background and the precise window: **lesson #277**.
- Deliberately not built in Slice 1; unchanged by Slice 4.

## 2. [#8c coordination] binding-grant → auto-SHARED hook

Call `autoOnShare(contractId, em)` inside the **grant transaction** so a
"Shared with me" binding grant starts the negotiation lane.

- Parked with the **#8c owner** — not this track's to land unilaterally.
- **The guard is ready:** `NegotiationStatusService.autoOnShare(contractId, em?)`
  (`backend/src/modules/contracts/services/negotiation-status.service.ts:129`)
  already takes an optional `EntityManager` and is idempotent / never moves the
  lane backward. The remaining work is the call site inside the grant txn.
- Today `autoOnShare` is called only from `ContractsService.updateStatus`
  (`contracts.service.ts:448`), without a manager.

## 3. [#8c-gated] Guest redline WRITES + counterparty accept-of-a-host-counter

Both stay closed until the **#8c-hardened guest surface** lands.

- **Guest writes:** `propose` / `counter` currently return a uniform **404** for
  guest accounts via `RedlineService.assertNotGuestWriter`
  (`redline.service.ts:164` and `:549`). `list` and the author's own `withdraw`
  stay open. Per lesson #278 the gate re-opens **atomically with** #8c's own
  hardening (limits / quotas / session posture), never as an earlier separate
  change.
- **Counterparty accept-of-a-host-counter:** a host counter sits `PROPOSED` with
  no counterparty-side accept path. Slice 1 treats a counterparty "accept" as a
  later slice's SIGNAL — never a direct cross-org clause write.

## 4. [follow-up] `preferred_language` frontend sync

The TopBar `LanguageToggle` writes `localStorage` only; until it PATCHes the
profile, most recipients resolve to `'en'`.

- Slice 4's backend resolver is correct and allowlisted
  (`redlines/utils/recipient-language.util.ts`) — the **input** is the gap, so
  Arabic-reading users still receive English notifications.
- Scoped OUT of Slice 4 deliberately (backend-only slice). Background: lesson #285.
- A separate ProfilePage dropdown already writes the column but does not change
  the UI, so this also fixes that pre-existing inconsistency.

## 5. [follow-up] Redlines deep-link — URL-synced tabs

`ContractDetailPage` tabs are local `useState` with **no URL sync**, so
`?tab=redlines` does nothing.

- Consequence today: redline notification emails link to `/app/contracts/:id`
  and the copy tells the recipient to open the Redlines tab. A Slice 4 test
  asserts no `?tab=` is emitted, so a fabricated param cannot creep in.
- Adding URL-synced tabs lets links target the tab directly; the notification
  copy and link can then be tightened.

## 6. [UX] Import button makes silent duplicate contracts
